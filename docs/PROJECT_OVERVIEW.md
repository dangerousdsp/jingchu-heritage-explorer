# 荆楚非遗 / Jingchu Heritage Explorer

荆楚非遗是面向公众的湖北非遗数字展馆。用户从中英文图鉴认识一门技艺，通过影像观察器物与表演，在地图上发现地区文化和参观地点，再将阅读、收藏和行程保存在自己的浏览器中。

1.0版收录146条地区记录与专题、22张附署名图片、73组地区参考位置及8个文化目的地。三维展馆按需加载保留的Unity WebGL场景，通过17份数据分片适配静态托管。完整网页无需安装Unity即可运行。

技术实现包含原生ES模块前端、Leaflet交互地图、OSRM多站道路规划、浏览器学习存储、Python本地服务和GitHub Actions自动校验与部署。

Jingchu Heritage Explorer is a public digital exhibition about the intangible cultural heritage of Hubei. Visitors discover traditions through bilingual cultural guides and photographs, explore regional heritage and visit destinations on an interactive map, and keep reading, favourites and trip records in their own browser.

Version 1.0 contains 146 regional entries and topics, 22 attributed images, 73 regional reference groups and eight cultural destinations. Its 3D exhibition loads the retained Unity WebGL scenes on demand, using 17 data chunks for static hosting. No Unity installation is needed to run the website.

The application uses native ES modules, Leaflet mapping, OSRM road planning, browser-local learning storage, a Python local server and GitHub Actions validation and deployment.
