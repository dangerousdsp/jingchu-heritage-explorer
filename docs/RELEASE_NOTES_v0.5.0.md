# Jingchu Heritage Explorer v0.5.0 / 荆楚非遗

## 中文

面向GitHub展示的整理版：中英文README、双语项目说明、网页中英文介绍、上传发布教程、测试与GitHub Pages工作流。

- 146条地区项目与专题、十门类、可追溯官方来源。
- 真实街道地图、73组地区参考点、8个公共文化目的地与多站道路规划。
- 本地阅读/收藏/行程记录、三题与十题练习、本地视频预览。
- 旧Unity按需接入与戏台左键环视适配，仅在另配原资源的本地版本提供。
- 公开包明确省略原Unity大文件与视频，保留来源和第三方许可证。

这是早期团队作品的个人后续Web重构。项目文档双语，主网页支持中英文切换，146条文化记录均有英文导读和观察点；原表机构名称、外部来源和旧Unity内部文字保留原文。原编钟卡顿、戏台物理问题、头显验证和第一/第三人称切换仍待后续处理。没有新授予覆盖全部项目资源的统一开源许可证。

## English

A GitHub presentation release with bilingual READMEs, project documentation, an on-site introduction, deployment guides, tests and a Pages workflow.

- 146 regional cultural entries and topics across ten categories, with traceable official sources.
- A street map, 73 regional reference groups, eight public cultural destinations and multi-stop road planning.
- Browser-local reading, favourites and trips; three- and ten-question quizzes; local video preview.
- On-demand legacy Unity integration and left-button theatre camera compatibility in the separately configured local resource edition.
- A public package that clearly excludes large Unity/video archives while retaining attribution and third-party licences.

A personal web continuation of an earlier team project. Documentation is bilingual; the web application supports Chinese and English cultural guides and controls. Legacy Unity text and original source records remain in their original language. Legacy chime freezes, theatre physics issues, headset verification and first/third-person switching remain future work. No blanket open-source licence is granted for all project resources.
