原有独立网页继续运行，新增 catalog-data.mjs、researched-topics.json、visit-places.json、travel.mjs、roadmap.mjs 和 explorer.css。content.mjs 合并原六专题和145条表格记录，以 FID 映射原 wood/chime/opera/lacquer/music，保留已有阅读、收藏和三维绑定；pottery 是额外原项目条目，合计146条。

原表原始行号、FID、项目编号、年份、单位与坐标均保留在生成数据或导入报告中，展示名称更正与原名称分别存储。145条表格记录均有简明介绍、观察点与官方来源。跨地区通用资料在各条sourceNote中说明适用范围。

## 地图与坐标

Leaflet 为本地固定版库，OSM 街道图按视口按需请求，有可见来源；不批量缓存、不预取离线瓦片。145条表格记录只有73组不同坐标，坐标系未注明，所以仅绘成地区参考点，不用于真实参观的算路坐标。

8个目的地使用独立核实的名称、官方地址及公开OSM WGS84点。区域参考层和目的地层可以分别切换。OSM建筑边界节点均值仅作场馆显示；黄鹤楼另有核实的停车场 routingPoint，规划与编号点使用该接驳点，场馆显示点仍保留。

地图、OSRM 均使用 WGS84。高德 URI 使用 GCJ02，通过本地 coordtransform 2.1.2 转换，不将 WGS84 直接传入。转换和道路接驳不保证当前开放入口，页面保留确认地点和官方来源。

## 行程与道路

行程最多8站，支持指定公共目的地作为出发点、去重、移除和手动换序。顺路建议是直线距离近邻，不宣称最短驾车时间。存储键 jingchu-heritage.travel.v1，与原阅读清单键独立；未调用设备定位。

用户主动规划后，本地 /api/route 仅接受已收录目的地 ID。服务端将其映射到核实坐标，不接受任意URL；2至8个不重复点、WGS84及湖北周边坐标范围需通过校验。浏览器与本地适配器均设置10分钟缓存和查询频率限制。OSRM请求18秒超时，响应限4MiB，简化结果，10分钟缓存，1.1秒频率限制。

纯静态托管 /api/route 返回404/405时，浏览器直接请求固定OSRM公共地址，已实测跨域成功。无密钥、无账户，也无隐藏第三方凭据。公共服务是演示依赖，并无可用性保证；公开大流量部署需配置合适的路由服务。仅在按钮点击时请求，不上传用户Excel、学习数据或设备位置。

道路结果是实线路径、距离/用时和逐步指引。修改行程立即清掉旧结果；异步版本号避免晚返回的旧路线覆盖新行程。查询失败时保留虚线顺序示意和逐段导航链接，明确区分。
